Lapis Obsidian Client is an independent, open-source HTML5 frontend with a bundled local transport bridge.

This preview includes a real WebGL scene, responsive controls, settings, and authenticated bridge lifecycle. Login, server worlds, inventory, chat, and gameplay are not implemented yet.

Original procedural artwork. No proprietary game assets.
